# AbsoluteBalls.net Desktop

Free Windows companion for Rocket League, with a live Player HUD and optional Replay Sync.

**[Download the Windows beta and see setup steps](https://absoluteballs.net/desktop)** · **[Analyze replays on the web](https://absoluteballs.net/rocket-league/replay-analysis)** · **[Join the community](https://discord.gg/H7WN2FBMCJ)**

## What it does

- **Player HUD:** view live match information and evidence-based guidance in a second-screen window.
- **Replay Sync:** optionally upload new or explicitly selected saved replays to Ballchasing. Replay Sync and the HUD are separate choices; upload visibility defaults to private.
- **Web analysis:** explore replay-backed statistics, benchmarks, and reports on AbsoluteBalls.net.
- **Community:** find setup help, discuss analysis, and share product feedback with players, coaches, analysts, developers, and league operators.

Rocket League is the current reference implementation of the broader AbsoluteBalls.net esports platform. This beta does not imply support for other games.

## Install and get started

1. Open the [official Desktop page](https://absoluteballs.net/desktop) for the current Windows installer and SHA-256 checksum.
2. Install and open AbsoluteBalls.net Desktop. Follow the in-app Player HUD setup for your Rocket League installation.
3. Enable Replay Sync only if you want saved replays uploaded through your Ballchasing connection.

Use [Getting Started](https://absoluteballs.net/welcome) or the [Help & FAQ](https://absoluteballs.net/faq) if you need a hand. The website's download page is the current-version source; this README does not pin an old installer.

## Evidence and trust

Live information is provisional; saved replay evidence supports deeper post-match analysis. Missing data stays unknown. Benchmark differences and correlations are not guarantees of wins.

Windows may display a SmartScreen reputation warning for a new beta installer. Verify the official download source and published checksum. A matching checksum confirms file integrity, not Microsoft certification or an independent security audit.
